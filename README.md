# FASHION POINT

A modern men's fashion e-commerce website built for FASHION POINT.

## 🛍️ About the Project

FASHION POINT is a production-style e-commerce website concept designed for a men's clothing and footwear store.

The website provides a modern shopping experience with product browsing, categories, search, wishlist, cart, reviews, orders, and other e-commerce features.

## ✨ Features

- 🏠 Modern responsive homepage
- 🔎 Product search with autocomplete
- 👕 Men's fashion product categories
- ⭐ Best Seller section
- 🏷️ Sale section
- ❤️ Wishlist
- 🛒 Shopping cart
- 📦 Orders and order tracking
- ⭐ Product reviews
- 🎨 Product colours and image galleries
- 🔍 Product image viewing and zoom
- 📱 Mobile-friendly responsive design
- 🔐 Admin dashboard
- 📊 Stock management
- 💳 Checkout and payment options

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Supabase
- Firebase Hosting

## 🎯 Project Purpose

This project was created as a complete e-commerce website demo for a men's fashion business and as part of the ANSARIWEBSTUDIO web development portfolio.
